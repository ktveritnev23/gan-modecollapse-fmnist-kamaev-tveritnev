# Коллапс мод в GAN: синтетика и Fashion-MNIST

Учебный эксперимент: два GAN с одинаковым критиком и разными функциями потерь (обычный BCE
против WGAN-GP со штрафом за градиент) обучаются на двух масштабах — на 8 гауссианах по кругу
(там видно, какие моды теряются) и на Fashion-MNIST (там видно, к чему это приводит на настоящих
картинках). Результат упакован в один короткий ноутбук, который обучает всё сам: гиперпараметры
вынесены в конфиг-ячейку, на каждую эпоху печатается строка метрик, в конце строятся кривые,
монтаж сэмплов и таблица сверки с эталонными прогонами.

## Что внутри

| Путь | Назначение |
|---|---|
| `notebooks/final_model_collapse_fashionmnist.ipynb` | повтор того же эксперимента на трёх сидах (42/43/44) с усреднением; обучается на GPU через ROCm/CUDA |
| `src/ganlib.py` | общая библиотека: модели G и D/критика, загрузка Fashion-MNIST, метрики мод (разметчик + k-means-покрытие), штраф за градиент, эталонный цикл обучения, выбор устройства (CUDA/ROCm/MPS/CPU) |
| `src/toy8.py` | синтетика: 8 гауссиан по кругу, BCE и WGAN-GP, метрики покрытия мод, прогон по нескольким сидам |
| `src/fid.py` | FID: признаки InceptionV3 из `pytorch_fid` + расстояние Фреше, кэш статистик |
| `src/fid_fashion_factorial.py` | FID архивных плеч Fashion-MNIST в отдельный JSON (не переобучает ничего) |
| `src/build_notebook_short.py` | сборка ноутбука; числа в прозе форматируются из JSON-артефактов, поэтому текст и выводы не расходятся (`--quick` — прогон на 3 эпохах) |
| `src/build_notebook_seeds.py` | сборка ноутбука на трёх сидах; `--finalize` запекает числа из `artifacts/notebook_seeds_run/run.json` в прозу, не перезапуская обучение |
| `requirements.txt` / `requirements-rocm.txt` | окружение для MPS/CPU и для AMD GPU (ROCm) соответственно |
| `artifacts/` | эталонные прогоны и статистики, которые ноутбук только читает |
